# data/synthetic

Generated demo data only, kept apart from `data/raw/` (REAL) and `data/derived/` (DERIVED).

Rules (docs/JALLEKHA_FINAL_SOLUTION.md, D18 and section 4 "Data rules"):

- Every file here has basis **SYNTHETIC** and is labelled on screen wherever it is shown.
- Generated by a script with a fixed seed; the script and seed are recorded next to the output.
- Calibrated to a REAL total where one exists (for example, monthly HMWSSB booking totals); the test that checks the calibration is named next to the output.
- Never hand-typed, and never copied into `data/raw/` or `data/derived/`.
