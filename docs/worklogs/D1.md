# `feat/d1-fetch` — `D1`

- **Owner / date:** P1 (Yaseer), 2026-10-01.
- **Purpose:** Fetch geospatial boundaries, infrastructure points, and document spatial raster/groundwater data sources for Hyderabad/GHMC with full provenance and integrity verification.
- **What we found:** Overpass API provides administrative boundary relations (admin_level 5/6 for district and 8 for mandals) and water infrastructure features within the Hyderabad bounding box (17.20,78.20,17.65,78.70). 129 HMWSSB/water infrastructure features (reservoirs, water towers, operator points) were identified and extracted. Google Open Buildings 2.5D Temporal (D6) and NWDP Groundwater Levels (D7) require authenticated portal/API access; comprehensive retrieval logs, exact URLs, schemas, licensing terms, and pipeline fallbacks were documented.
- **What we changed:**
  - Added `scripts/data/fetch_d1.py` supporting live Overpass fetch with exponential backoff, `--skip-fetch` for deterministic CI manifest recomputation, and `--dry-run`.
  - Added `scripts/data/verify_d1.py` to assert GeoJSON schema validity, SHA-256 integrity, byte count, ODbL licence, and retrieval logs.
  - Added raw GeoJSON data under `data/raw/geography/osm/`: `hyderabad_district.geojson`, `hyderabad_mandals.geojson`, and `hmwssb_points.geojson` (129 features).
  - Added `data/verification/d1_manifest.csv` tracking 12 metadata fields per source.
  - Added `data/raw/d6_open_buildings/RETRIEVAL_LOG.md` and `data/raw/d7_groundwater/RETRIEVAL_LOG.md`.
  - Added unit test suite in `backend/tests/test_d1_data.py`.
  - Added `verify_d1.py` check to `tasks.py` test runner.
  - Added GitHub Actions workflow `.github/workflows/p1-d1.yml`.
- **Validation:**
  - `python scripts/data/fetch_d1.py --skip-fetch` recomputes manifest with zero network overhead.
  - `python scripts/data/verify_d1.py` verifies all 3 OSM layers and retrieval logs.
  - `python scripts/data/verify_manifest.py` verifies all 33 S2 raw files remain unaltered.
  - `pytest backend/tests` passes 5 tests (test_health + test_d1_data suite).
  - `ruff check` and `ruff format --check` pass on backend, scripts, and tasks.py.
- **Known limitations:** D6 (Open Buildings) and D7 (NWDP groundwater) are documented with retrieval logs awaiting authenticated exports; downstream features (E3, T2, T8) use documented fallbacks if credentials are not provided.
- **Handoff / next step:** D1 unblocks E1 (Ward polygons + Census crosswalk) and E2 (Ward evidence table).
