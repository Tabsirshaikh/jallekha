## Findings

## Changes
Build one row per historical polygon ID, preserving both Ward 37 geometries.
Ambiguous or missing crosswalk/HH-14 joins leave all Census values empty.
Unique joins are PROVISIONAL_NUMBER_ONLY, review_required=true and allocation_eligible=false.
Every metric has a _basis and source identifiers. Raw files are untouched.
WAD=(near+away)/100. Non-tap share=1-(treated+untreated tap)/100 is separate:
the plan supplies no approved smaller weight. CAD=1-(landline+mobile+both)/100.
Hardship is the mean of one-room-or-less, dilapidated, and no-assets shares;
these overlap, so it is a descriptive proxy, not the fraction of deprived households.
Facilities remain empty. Missing values never become zero. Out-of-range values remain unknown.
Round-off tolerance is 0.01 percentage points per component, with bounded clamping.
Headers are checked; source/output SHA-256 hashes and artifacts are reproducible.
