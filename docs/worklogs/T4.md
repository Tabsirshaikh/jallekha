# `feat/t4-intake` — `T4`

- **Owner / date:** P3, 2026-10-02.
- **Purpose:** Build F14 unified intake: every channel (app, SMS, missed call, field worker, voice, offline sync) through one pipeline into a `Complaint`, with spam filtering, language by script, deterministic categories in four languages and T1 duplicate merging; voice notes never lost.
- **What we found:** P2's `IntakeMessage` (S3) has no fields for `reported_for`, `reporter_id`, client time or audio, so T4 wraps it (`IntakeItem`) instead of changing it. The missed-call rule is already labelled ASSUMED in `services/intake.py` (S3 review D14). No ledger event type fits intake (`issue_status_changed` is for status changes), so none was added. There is no resident phone registry and no area boundary at intake, so two spam signals are partly unavailable. `python-multipart` is not installed, so voice upload over HTTP waits for T10. IndicConformer covers Telugu, Hindi and Urdu (`docs/research/P3.md` F14) but has no published Telugu / Urdu error rate and no confidence output. While writing the keyword lists, a script check found one Cyrillic letter in a Latin keyword; it was fixed and every list is checked to use only its own script.
- **What we changed:** `config/intake.py` (keyword lists te / hi / ur / en, SMS field names, OPEN values), `.env.example` (`PHONE_HASH_KEY`, `INTAKE_AUDIO_DIR`), `.gitignore` (`/uploads/`); models: `complaint` (optional location, `category_basis`, `language_basis`, `transcript_confidence`, `needs_human_transcription`, `reporter_id`, `status`), new `intake_item` and `voice_note`; `services/intake_pipeline.py`; `routers/intake.py` + `main.py`; tests `backend/tests/services/test_intake_pipeline.py`, `backend/tests/test_intake_models_router.py`.
- **Validation:** Tests written first. 48 new tests pass (each channel, spam, Telugu / Hindi / Urdu, address-only text, idempotent client ids, batch with a bad item, voice fallback, field-worker household link, T1 merge, privacy and ledger payload checks, endpoints). `python tasks.py test` exit 0: 371 backend passed, 1 frontend test, all P1 verifiers. `python tasks.py lint` exit 0. Test data is synthetic (made-up phone numbers, ids and texts written for the tests); no real data used.
- **Known limitations:** OPEN, owner to confirm: keyword lists (native-speaker review), report time for offline items (`server` proposed), phone registry (none yet), ASR model revision pin. ASSUMED: missed call = no water; Latin text = English. Reports without a location are not deduplicated. The IndicConformer path is not run in tests. No voice upload endpoint and no authentication until T10. No ledger logging until intake event types exist and T6 is merged.
