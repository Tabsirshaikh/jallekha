# `feat/e1-crosswalk` — `E1`

- **Owner / date:** P1 (Yaseer), 2026-10-01.
- **Purpose:** Construct a versioned historical Census 2011 to GHMC 2016 (150-ward) crosswalk that safely links Census PCA population and household metrics to available historical ward boundaries without false geographic matches.
- **What we found:**
  - Census 2011 covers GHMC across two districts: Hyderabad District (99 GHMC ward rows, 8 Secunderabad Cantonment Board rows, 1 Osmania University Census Town row) and Rangareddy District (54 GHMC ward rows). Total source rows: 162.
  - DataMeet GeoJSON layer (`GHMC_2016_150`) contains 145 polygon features across 144 unique ward numbers (with Ward 37 having two polygon parts: Rein Bazar and Kurmaguda).
  - Wards 3, 4, 11, 13, 31, and 113 are known missing polygons in the DataMeet layer.
  - Census Hyderabad Ward 104 and 107 are in Shaikpet mandal and conflict geographically with DataMeet Ward 104 (Kondapur) and Ward 107 (Madhapur) located in Serilingampally circle. Naive joins on number alone would cause cross-mandal corruption. Per acceptance criteria, wards 104 and 107 are **never matched**.
  - Non-GHMC areas in Hyderabad PCA (Secunderabad Cantonment Board and Osmania University) are retained unmatched (`unmatched_non_ghmc`).
  - Table HH-14 in Census has printed 1-based indices in row 6; programmatic array access requires 0-based column indices with asserted header names.
- **What we changed:**
  - Added `scripts/evidence/build_crosswalk.py` to construct:
    - `data/derived/crosswalk/census_to_ghmc_2016.csv` (162 source rows mapped with full provenance, one-to-many weights, mapping methods, and basis `DERIVED`).
    - `data/derived/crosswalk/crosswalk_summary.json` (reporting 94.77% GHMC ward coverage, 90.47% population coverage, never-matched validation, and missing ward counts).
    - `data/verification/crosswalk_checks.json` (machine-readable checks and SHA-256 hashes).
  - Added `scripts/evidence/verify_crosswalk.py` to enforce all invariants, geographic freeze at `GHMC_2016_150`, zero 104/107 matches, zero false matches on missing polygons, and HH-14 header assertions.
  - Added unit test suite in `backend/tests/test_e1_crosswalk.py` verifying all rules, data integrity, and edge cases.
  - Updated `tasks.py` to run crosswalk verification during `tasks.py test`.
  - Added GitHub Actions workflow `.github/workflows/p1-e1.yml` (`P1:E1`).
  - Updated `docs/features.csv` marking E1 as `DONE`.
